# ContactMirror 0.6.0

## Главное

Локальный MCP-сервер позволяет агентам работать с ContactMirror через 38 инструментов: читать и редактировать контакты, фотографии и ярлыки, искать и фильтровать записи, готовить и применять планы синхронизации, просматривать историю и восстанавливать данные.

## Добавлено

- Общий исполнитель для окна приложения и MCP-клиентов; агенты могут работать без открытого окна.
- Настройки доступа с разрешёнными папками и отдельными правами на локальные изменения и работу с Google. MCP по умолчанию выключен.
- Сохранённые результаты операций и ключи запросов для безопасного повтора после обрыва соединения.
- Конфигурация MCP-клиента копируется из настроек; инструкции входят в пакет (`docs/MCP.md`).

## Совместимость

- Сохраняются формат папки, App ID `ContactMirror.Desktop`, канал `win` и источник обновлений GitHub. Уже установленная 0.5.0 может получить полный пакет без промежуточных версий.
- Несохранённые правки и открытые формы защищены от записей агента. Перед обновлением программы завершите MCP-клиенты, использующие файлы текущей версии.
- Неизвестные существующие категории контакта сохраняются при правках остальных полей и доступны только для чтения.

## Известные ограничения

- Google OAuth остаётся в режиме Testing; установщик не подписан.
- Проверки MCP используют вымышленные данные и контрактные Google gateways; они не подтверждают живую синхронизацию с личным Google-аккаунтом.
- Подготовка сравнения для 10 000 контактов может превышать ориентир 5 секунд; ускорение в этом релизе не заявляется.
